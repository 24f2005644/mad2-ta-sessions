Vue Lifecycle Code Quiz

Read the code and predict the output before showing the answer.

1. What is the correct console order?

data() {
    console.log("data");
    return { message: "Hi" };
},
beforeCreate() { console.log("beforeCreate"); },
created() { console.log("created"); },
mounted() { console.log("mounted"); }

beforeCreate → data → created → mounted

2. Predict both values in `beforeCreate()`.

data() {
    return { message: "Hello" };
},
beforeCreate() {
    console.log(this.message);
    console.log(this.showMessage);
}

Both are undefined because data and methods are not ready in beforeCreate().

3. Which values are available in `created()`?

data() {
    return { message: "Hello" };
},
computed: {
    upperMessage() {
        return this.message.toUpperCase();
    }
},
created() {
    console.log(this.message);
    console.log(this.upperMessage);
    console.log(this.$el);
}

message = "Hello", upperMessage = "HELLO", and $el is not the mounted DOM yet.

4. How many times does the computed property run?

computed: {
    upperMessage() {
        console.log("computed");
        return this.message.toUpperCase();
    }
},
mounted() {
    console.log(this.upperMessage);
    console.log(this.upperMessage);
}

Once. Vue caches a computed value until its dependency changes.

5. What is the output after clicking the button once?

data() {
    return { count: 0 };
},
methods: {
    add() {
        this.count++;
    }
},
beforeUpdate() { console.log("beforeUpdate"); },
updated() { console.log("updated"); }

count changes from 0 to 1, then beforeUpdate runs, followed by updated.

6. What is logged by this method call?

data() {
    return { message: "Hello" };
},
methods: {
    showMessage() {
        console.log(this.message);
    }
},
created() {
    this.showMessage();
}

Hello. Methods and data are available in created().

7. Which line works, and which line does not?

created() {
    console.log(this.$el.innerHTML);
},
mounted() {
    console.log(this.$el.innerHTML);
}

The mounted() line works because the DOM is ready. The created() line cannot safely read the mounted DOM.

8. What is the lifecycle order after clicking `destroyApp()`?

methods: {
    destroyApp() {
        this.$destroy();
    }
},
beforeDestroy() { console.log("before"); },
destroyed() { console.log("after"); }

beforeDestroy() runs first, then destroyed().
